# Budget Tracker App Prototype

This is a budget tracker Android app prototype developed as part of an assignment. The app allows users to log in, create categories, add expense entries with details and optional photos, set monthly spending goals, and view expenses and totals by category for selectable periods. Data is persisted locally using RoomDB.

## Features

- User login with username and password
- Category creation and management
- Expense entry with date, start/end times, description, category, and optional photo
- Set minimum and maximum monthly spending goals
- View expense entries list filtered by user-selectable period, with photo access
- View total money spent per category for user-selectable period
- Data persistence using SQLite
- User-friendly interface with input validation
- Logging for understanding code flow
- Automated testing of main functionality
- CI/CD with GitHub Actions for automated build and test
- Built APK included for installation

## Setup

1. Clone the repository
2. Open the project in Android Studio
3. Build and run the app on an emulator or device
4. Use the app features as described
